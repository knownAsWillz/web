# William Jefferson Demillo · Portfolio

Personal portfolio with a built-in assistant page.

- **Portfolio:** about, projects (with case studies for private work), experience and contact.
- **Assistant** (`#chat`): checks job fit against a pasted job post, finds and explains projects, answers questions about achievements and ventures, and drafts an email to me. Answers are pre-written for now; a Cloudflare Workers AI model will be connected later.
- **Themes:** System, Ivory, Charcoal, Midnight and Sage, remembered per visitor.

Single static page with no build step: open `index.html` or serve the folder.
